# Tayson PS4 Payload Generator 3.4.3

Aplicativo Android para validar PKGs, preparar o payload e enviá-lo ao PS4.

## Recursos

- validação de PKG;
- geração dinâmica de payload;
- metadados e artwork;
- suporte aos provedores compatíveis;
- histórico local;
- Worker complementar configurável.

## Provedores compatíveis

- Mocha
- VikingFile
- FileKeeper
- Rootz
- AkiraBox
