# Security and disclosure

Do not publish sensitive operational data in issues, logs, screenshots or release notes.

Examples:

- signed or temporary URLs;
- cookies and access tokens;
- IP addresses;
- account identifiers;
- private endpoints;
- infrastructure bindings;
- credentials or secrets.

When reporting a problem, redact those values and include only the minimum information required to reproduce the issue.

If a secret or credential is exposed, revoke or rotate it before continuing.
